## Figure 5 reconciliation

The plotting script reports `start + contributions - endpoint`. Most region-periods equal 0.0. The following residuals were observed:

- FW, 2001–2013: −1.0
- NC, 2001–2013: +1.0
- EC, 2001–2013: +1.0
- EC, 2013–2020: −1.0

All other regional periods reported 0.0. These are consistent with endpoints rounded to whole units while contributions are stored at whole or one-decimal precision. They were not silently corrected.

The original Figure 4 R script referenced a missing file named `Figure4数据.xlsx`. A root-level workbook named `2001-2013和2013-2020-动态-各区域柱状图 - 副本.xlsx` has the expected regional sheets and five-column schema and was mapped to the repository's `Figure4_relative_contributions.xlsx` for the successful rendering test. This is a documented file-identification decision, not proof that it is the original upstream output; the authors must confirm it.

For the China worksheet, both periods reconcile exactly at the stored precision:

- `852 + 236.5 − 60.9 − 9.6 = 1018`
- `1018 + 48.6 + 11.7 + 9.7 = 1088`

## Important interpretation

The successful figure runs demonstrate that the existing publication artwork can be regenerated from already-derived local files. They do **not** demonstrate end-to-end reproduction of the paper's results from raw data. Figures 3, 4, and 6 are especially presentation-level reproductions: Figure 3 uses existing SHAP products, Figure 4 reads precomputed shares and manually transcribed signs, and Figure 6 redraws already-estimated paths.

## Environment issues

- The first R run failed because the inherited `C.UTF-8` locale corrupted a path containing Chinese characters. Setting a valid Windows UTF-8 locale resolved the path error.
- The first Figure 3a/3c run failed with `FileNotFoundError` because the required PPTX/SVG/PNG source artwork had intentionally not yet been copied. The existing source files were then copied into the Git-ignored local review area and the scripts passed. Those large source files remain `DO_NOT_UPLOAD` or `HOLD` items, so a clean public clone will not reproduce Figure 3 unless approved replacements are deposited separately.
- Arial is required by the R plotting scripts and by some raster-annotation code. Cross-platform users may need to install Arial or explicitly approve a substitute; substitution can change layout.
- `sf` and `ragg` require system libraries whose installation differs across Windows, macOS, and Linux.
- `xgboost`, `shap`, and `semopy` were absent from the verified Python plotting environment; no missing analysis scripts were available to determine the correct packages or versions.
